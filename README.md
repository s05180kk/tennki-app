# 気象予報士 一問一答アプリ

気象予報士試験（学科一般・学科専門）の過去問PDFから問題を取り出して、ブラウザで使う一問一答アプリにします。

- **○× 一問一答**：正誤問題の各文 (a)〜(d) を1文ずつ出題します。正誤は公式解答例の正解番号から自動で割り出します。
- **五択 過去問**：本番と同じ形式で1問ずつ出題します。
- 学習記録（正答率・苦手）はブラウザの localStorage に保存されます。各問題から原本PDFの該当ページを開けます。

> 試験問題は無断転載が禁止されているため、このリポジトリには問題PDFも、そこから生成した `data.js` も含めていません。
> 使うときは手元の過去問PDFから `data.js` を生成してください。

## 使い方

1. 過去問PDFを次の構成で置きます。

   ```
   気象予報士試験_過去問/
     第66回_2026年8月/
       01_学科一般問題.pdf
       02_学科専門問題.pdf
       ..._学科・実技解答例.pdf
   ```

2. データを生成します（Node.js が必要です。Windows 標準の游ゴシックなどのフォントを使って文字化けを直すため、Windows で実行してください）。

   ```
   cd tools
   npm install
   npm run build
   ```

3. `一問一答アプリ/index.html` をブラウザで開きます。

## 構成

| パス | 内容 |
| --- | --- |
| `一問一答アプリ/index.html` | アプリ本体（1ファイル） |
| `tools/extract.mjs` | pdf.js でPDFからテキストを抽出（ToUnicode のないフォントはシステムフォントの cmap でグリフIDを文字に戻す） |
| `tools/ttfmap.mjs` | TrueType/TTC の cmap を読む |
| `tools/parse.js` | 問題・選択肢・正誤表・解答を構造化 |
| `tools/build-data.js` | アプリ用の `data.js` を出力 |
